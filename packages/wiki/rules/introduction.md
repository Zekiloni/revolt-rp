# Revolt Roleplay – Official Rulebook

Welcome to **Revolt Roleplay**, a text-based Heavy Roleplay server based on GTA V and RAGE Multiplayer (RAGE:MP).  
This contains the complete set of rules that all players must follow to ensure realistic, respectful and immersive roleplay.

---
## 1 Introduction

Revolt Roleplay is a **text-based, heavy roleplay server** set mainly in **Blaine County**, inspired by the towns of Sandy Shores, Grapeseed, and Harmony.  
We aim to create a believable world where characters have depth, actions have consequences and realism is more important than winning.

- All interactions must be written using in-game text commands.
- **Roleplay comes first.** Scripts and mechanics exist only to support RP, not to replace it.
- **Your character is not you.** IC (in-character) actions must stay separate from OOC (out-of-character) knowledge.

---

## 1.1 Basic Definitions & Terms

| Term | Meaning |
|------|---------|
| **IC (In Character)** | Anything your character does, says or experiences in the game world. |
| **OOC (Out of Character)** | Anything outside of roleplay — real-life discussions, technical issues, Discord chats. |
| **/b or /ooc** | Command used to speak out of character in-game. Only for short, necessary messages. |
| **Metagaming** | Using OOC information for IC advantage. Strictly forbidden. |
| **Powergaming** | Forcing actions on others or doing unrealistic actions without giving chance to react. |
| **FearRP** | Your character must show fear for their life when threatened realistically. |
| **PK (Player Kill)** | Your character forgets the events leading to death, but continues living. |
| **CK (Character Kill)** | Permanent death. Character is removed from play and must be name-changed. |
| **RDM / Deathmatching** | Killing or attacking another player without proper IC reason or escalation. |
| **Leaving The Action (LTA)** | Leaving the server to avoid RP consequences. |

---

## 1.2 Basic Roleplay Principles

1. **Act as if this world is real.**  
   Every action your character takes should make sense in a realistic setting.

2. **Actions have consequences.**  
   Crime, injuries, corruption and violence will affect your character long-term, so consider roleplaying consequences.

3. **Respect the story.**  
   Roleplay is about cooperation, not winning. You are writing a story with others.

4. **Heavy RP standard.**  
   We expect detailed roleplay, detailed /me and /do usage, realistic behavior and character development.

---

## 1.3 Server Philosophy

Revolt Roleplay is built on four core values:

- **Immersion** – We aim for realism and continuity in every situation.  
- **Respect** – Every player deserves a fair and enjoyable experience.  
- **Creativity** – Your character is unique. Develop them with depth.  
- **Accountability** – Rule breaks will always have consequences.

---

## 1.4 Using This Rulebook

- These rules apply everywhere: **in-game, Discord, forums, social media**.  
- If something is not written, it does **not mean it is allowed**. Use common sense.  
- If unsure, ask staff members and they will gladly help you.  
- Administrators always have the final word in interpreting rules.
