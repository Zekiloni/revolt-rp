# Phone System

---

## 1. How to Use the Phone

| Action | Key |
|--------|-----|
| Take phone out | **Arrow Up (↑)** |
| Put phone away | **Arrow Down (↓)** |
| Alternative | Place phone in quick slot (1–5) & press number |
| Open from inventory | Right-click → Use |

---

## 2. Phone Features & Default Apps

| App / Function | Description |
|----------------|-------------|
| **Contacts** | Save, edit, delete phone numbers |
| **Messages (SMS)** | Send/receive messages to players or services |
| **Phone Calls** | Voice calls between players / emergency services |
| **Bank / Wallet App** | Check balance, transfers, savings if phone is linked to a bank card |
| **Camera** | Take photos, saves to gallery |
| **Notes** | Personal note system |
| **Weather App** | Shows AI-generated in-game weather forecasts |
| **Map & GPS** | View map, search locations, set waypoints, send location to other players via message |
| **Advertisements** | Browse public ads or create new ones (*paid service*) |
| **Settings App** | Change ringtone, volume, wallpaper, notifications |

> ⚠ If your phone is stolen and not locked/unlinked from the bank, another player may access your bank account.

---

## 3. Multiple Phones

- Players can own **more than one phone**.
- Each phone have a different **number**.
- Losing or giving away a phone = losing access to contacts, banking (if linked), and messages.

---

## 4. Phone + Banking Connection

| Banking Feature | Requirement |
|------------------|-------------|
| Transfer money via phone | Phone must be linked to bank account |
| View account balance | Linked phone + Banking app |
| Pay taxes/bills | Available if phone is verified to account |
| Disable banking on lost phone | Use bank menu → unlink phone |

---

## 5. How to Add a Contact

1. Open **Contacts App**
2. Click **“Add New”**
3. Insert:
   - Name
   - Phone number (numeric)
4. Save  

Contact is now synced on this phone only

---

## 6. Ad System

- From the **Advertisements App**:
  - View other players' ads
  - Create your own ad (**cost is deducted from balance**)
- Ads can be:
  - Vehicle for sale
  - Business announcement
  - Job offers / services
  - Rent, real estate, etc.
  - Private or public (contact)
