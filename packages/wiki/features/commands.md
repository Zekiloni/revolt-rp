# Commands Overview

This page lists all important player commands organized by category.

Each command includes:
-  Command name  
-  Usage example  
-  Description (what it does)

Every command is listed and explained at **`/help`** menu in-game.

---

## 1. In-Character (IC) Communication

| Command | Example | Description |
|---------|---------|-------------|
| **/me** | `/me slowly lights a cigarette.` | Describes your character’s physical action. |
| **/ame** | `/ame checks the time.` | Short action shown above your character's head. |
| **/do** | `/do The room smells like gasoline.` | Describes environment, visible facts or responses. |
| **/try** | `/try breaks the window with his elbow.` | Attempts an action with success/fail outcome. |
| **/shout**| `/shout Stop running!` | Shouts loudly within a large radius. |
| **/low**| `/low (quietly) We shouldn’t be here.` | Speaks quietly — short hearing distance. |
| **/whisper**| `/w 15 Take this and leave.` | Private whisper to ID 15 nearby. |
| **/pm** | `/pm 12 Where are you?` | Private message to a player (OOC). |
| **/giveup** | `/giveup` | Used when injured/dying to confirm death. |

---

## 2. Out-of-Character (OOC) Chat

| Command | Example | Description |
|---------|---------|-------------|
| **/b** | `/b I crashed, can we re-rp?` | Local OOC chat — visible to nearby players. |
| **/pm** | `/pm 22 Restart your client.` | Private message to specific player. |
| **/clearmychat** | `/clearmychat` | Clears chat on your screen only. |
| **/coin** | `/coin` | Flip a coin — returns Heads/Tails. |
| **/id** | `/id 19` | Shows info about player with ID 19. |

---

## 3. Vehicle Commands

| Command | Example | Description |
|---------|---------|-------------|
| **/engine** | `/engine` | Starts/stops engine (same as holding Y). |
| **/hood** | `/hood` | Opens or closes vehicle hood. |
| **/trunk** | `/trunk` | Opens vehicle trunk (inventory). |
| **/windows** | `/windows 2` | Opens/closes window (index 1–4). |
| **/lastvehicle** | `/lastvehicle` | Teleports you to your last driven vehicle (admin/tool). |
| **/lock** | `/lock` (or press L) | Locks/unlocks your owned vehicle. |
| **/seatbelt** | `/seatbelt` or `B` | Toggles seatbelt. |

---

## 4. Property & Housing

| Command | Example | Description |
|---------|---------|-------------|
| **/property** | `/property` | View your owned properties. |
| **/enter** | `/enter` | Enter a property interior. |
| **/exit** | `/exit` | Exit property interior. |
| **L (key)** | — | Lock/unlock home or property door. |

## 5. Money & Banking Commands

| Command | Example | Description |
|---------|---------|-------------|
| **/pay** | `/pay 23 500` | Pays $500 to player ID 23 (must be nearby). |

## 6. Organization & Faction Commands

| Command | Example | Description |
|---------|---------|-------------|
| **/org** | `/org` | Opens organization panel. |
| **/f** | `/f Meeting at HQ.` | Sends message to faction chat. |
| **/invite** | `/invite 27` | Invite player ID 27 to organization. |
| **/uninvite** | `/uninvite 27` | Remove player from organization. |
| **/leaveorganization** | `/leaveorganization` | Leave your current organization. |
