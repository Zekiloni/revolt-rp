# Keybinds & Controls

---

## 1. Player Menu (Home Key)

**`HOME`** opens the **Player Menu**:

You can view:
- Your character information
- Bank accounts & finances
- Owned vehicles
- Owned properties
- Organizations (if you're a member)
- Online players list
- Settings & preferences (UI etc.)

---

##  2. Interaction & Roleplay Keys

| Key | Function |
|-----|----------|
| **Y** | Interact with items (pick up, object interactions). For vehicles: Short press = interaction menu. Hold 2s = start/stop vehicle engine. |
| **F3** | Force toggle cursor (useful if mouse cursor gets stuck). |
| **R** | Reload weapon (if correct ammo type is in inventory). |
| **L** | Lock / unlock nearest owned vehicle or property. |
| **B** | Seatbelt on/off while in vehicle. |
| **F7** | Toggle HUD visibility on/off. |
| **↑ (Arrow Up)** | Open phone. |
| **↓ (Arrow Down)** | Put phone away. |
| **Left/Right Arrow** | Vehicle turn signals. |
| **Numbers 1–5** | Quick Item/Weapon slots. Instantly equips or holds the item. |

---

## 3. Emotes, Animations & Styles

**Key: `M` — Animation & Expression Menu**

From here you can:
- Play emotes / animations
- Change walking styles
- Set facial expressions
- Access radial animation menu for quick selection

---

## 4. Phone & Quick Access

| Action | Key |
|--------|-----|
| Open phone | **Arrow Up** |
| Hide phone | **Arrow Down** |
| Quick use from inventory | Place phone in quick slot (1–5) |
| F3 + Mouse | Interact with apps |

---

## 5. Vehicles – Controls

| Key / Action | Description |
|--------------|-------------|
| **Y (Tap)** | Open vehicle menu (doors, seats, interior options). |
| **Y (Hold 2s)** | Start/stop engine. |
| **B** | Seatbelt toggle. |
| **L** | Lock/unlock vehicle. |
| **Left/Right Arrow** | Blinkers (turn signals). |
| **/windows** | Command to open/close windows (index required). |
| **Hood/Trunk via Y** | If standing near front or back — opens hood/trunk inventory. |

---

## 6. Weapon Controls

| Action | Key |
|--------|-----|
| Equip weapon | Place in quick slot → press **1–5** |
| Reload | **R** (if correct ammo is in inventory) |
| Holster weapon | Press same quick slot number again |
